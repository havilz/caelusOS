# installer/branding

Direktori ini berisi aset branding visual Calamares Installer untuk CaelusOS.

## Daftar Berkas & Sub-Direktori

* branding/caelus/branding.desc : Berkas deskripsi identitas visual, skema warna, dan nama distro CaelusOS di installer.
* branding/caelus/show.qml : Berkas komponen QML slideshow interaktif yang tampil saat menyalin file sistem.

## Instruksi Modifikasi

Slideshow QML di show.qml wajib menampilkan keunggulan fitur CaelusOS (Developer OS, Docker ready, Caelus Developer Toolbox).
