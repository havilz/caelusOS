# packages/caelus-welcome/usr/share/caelus-toolbox/lib

Direktori ini berisi pustaka fungsi pendukung (helper utilities) dan variabel warna ANSI yang digunakan oleh engine caelus-toolbox.

## Daftar Berkas & Sub-Direktori

* colors.sh : Definisi variabel warna ANSI terminal khas CaelusOS (cyan, purple, dark gray, white).
* utils.sh : Fungsi helper umum seperti pengecekan koneksi internet, animasi spinner, dan pencetakan log.

## Instruksi Modifikasi

Fungsi di dalam direktori lib dibuat agar dapat digunakan kembali secara modular oleh seluruh berkas skrip di folder modules/.
