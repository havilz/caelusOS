# packages

Direktori ini berisi paket-paket kustom, identitas visual, tema gelap, animasi booting, serta pengaturan default sistem yang menjadi ciri khas CaelusOS.

## Daftar Berkas & Sub-Direktori

* caelus-settings/ : Paket pengaturan default sistem (/etc/os-release, grub config, profil dconf, dan template user /etc/skel).
* caelus-artwork/ : Koleksi aset visual, wallpaper high-res, tema GTK gelap Caelus-Dark, ikon Caelus-Circle, dan logo SVG/PNG.
* caelus-plymouth/ : Tema animasi splash screen saat proses booting komputer dinyalakan.
* caelus-welcome/ : Aplikasi sistem Welcome dan engine Caelus Developer Toolbox (caelus-toolbox).

## Instruksi Modifikasi

Setiap modul di dalam direktori packages diisolasi secara mandiri. Modifikasi pada satu modul tidak mempengaruhi modul lainnya.
