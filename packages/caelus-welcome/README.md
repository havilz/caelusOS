# packages/caelus-welcome

Direktori ini berisi aplikasi Welcome Screen dan perkakas CLI interaktif Caelus Developer Toolbox (caelus-toolbox).

## Daftar Berkas & Sub-Direktori

* usr/bin/caelus-welcome : Executable skrip launcher aplikasi GUI Welcome CaelusOS.
* usr/bin/caelus-toolbox : Executable launcher penunjuk ke engine TUI Developer Toolbox.
* usr/share/applications/ : Desktop entry shortcut menu aplikasi.
* etc/xdg/autostart/ : Konfigurasi auto-launch saat pengguna pertama kali masuk ke desktop.
* usr/share/caelus-toolbox/ : Direktori engine utama dan modul-modul SDK auto-installer.

## Instruksi Modifikasi

Seluruh modul instalasi SDK diletakkan di dalam subfolder usr/share/caelus-toolbox/modules/.
