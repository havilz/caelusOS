# packages/caelus-plymouth

Direktori ini berisi tema animasi boot splash screen Plymouth yang tampil saat komputer dinyalakan atau dimatikan.

## Daftar Berkas & Sub-Direktori

* usr/share/plymouth/themes/caelus/caelus.plymouth : Berkas konfigurasi utama tema Plymouth CaelusOS.
* usr/share/plymouth/themes/caelus/caelus.script : Skrip animasi Plymouth untuk merotasi logo CaelusOS dan progress bar.

## Instruksi Modifikasi

Skrip Plymouth dieksekusi di lingkungan awal booting (initramfs). Pastikan ukuran aset gambar dioptimalkan agar booting tetap cepat.
