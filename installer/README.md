# installer

Direktori ini berisi konfigurasi antarmuka dan modul logika untuk Calamares GUI Installer yang digunakan untuk memasang CaelusOS ke dalam disk/SSD komputer pengguna.

## Daftar Berkas & Sub-Direktori

* settings.conf : Berkas master konfigurasi urutan pipeline instalasi Calamares.
* branding/ : Direktori aset visual, warna, logo, dan slideshow promosi CaelusOS saat proses instalasi berjalan.
* modules/ : Direktori modul-modul konfigurasi instalasi (selamat datang, bahasa, partisi disk, akun pengguna).

## Instruksi Modifikasi

Seluruh penyesuaian tampilan wizard instalasi diatur melalui subfolder branding/caelus/.
