# packages/caelus-artwork

Direktori ini berisi seluruh aset grafis dan elemen visual utama yang membentuk identitas CaelusOS.

## Daftar Berkas & Sub-Direktori

* usr/share/backgrounds/caelus/caelus-wallpapers.xml : Metadata daftar koleksi wallpaper high-resolution CaelusOS.
* usr/share/icons/Caelus-Circle/index.theme : Konfigurasi tema ikon sistem kustom berbasis lingkaran gelap.
* usr/share/themes/Caelus-Dark/index.theme : Metadata tema visual Caelus-Dark.
* usr/share/themes/Caelus-Dark/gtk-3.0/gtk.css : Stylesheet GTK 3.0 dengan estetika Deep Space Dark Glassmorphism.
* usr/share/pixmaps/ : Berkas logo resmi CaelusOS dalam format SVG dan PNG.

## Instruksi Modifikasi

Gunakan token warna resmi CaelusOS (#0f111a Deep Space Dark, #00d2ff Electric Cyan, #7928ca Nebula Purple) saat membuat atau memperbarui tema dan ikon.
